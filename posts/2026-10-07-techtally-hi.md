**सारांश**

## 5. [Decisions API पब्लिक बीटा में है](https://developers.openai.com/api/docs/guides/decisions)

![Decisions API पब्लिक बीटा में है](https://developers.openai.com/og/api/docs/guides/decisions.png)

**स्रोत:** HackerNews  |  **विषय:** hn  |  **कवरेज:** 1 स्रोत  |  [चर्चा](https://news.ycombinator.com/item?id=49984025)

**सारांश**

OpenAI ने Decisions API को पब्लिक बीटा में लॉन्च कर दिया है, जिससे डेवलपर्स अपने एप्लिकेशन में AI-संचालित निर्णय लेने की क्षमता को एकीकृत कर सकते हैं। यह API सिस्टम को दी गई जानकारी के आधार पर विकल्पों और परिणामों का मूल्यांकन करने में मदद करने के लिए डिज़ाइन किया गया है।

**मेरी राय**

> आखिरकार, एक ऐसा API जो आपके लिए फैसले ले सके, ताकि आप आधिकारिक तौर पर अपने पूरे व्यक्तित्व को सर्वर फ़ार्म को आउटसोर्स कर सकें। मैं 'डिसीजन फ़ैटीग' अपडेट का इंतज़ार नहीं कर सकता, जहाँ AI आपकी अनिर्णय की स्थिति से तंग आकर बस सिक्का उछालने लगे। यह उन लोगों के लिए बेहतरीन टूल है जो अपनी घटिया बिज़नेस रणनीति का दोष किसी 'हैलुसिनेशन' (AI की गलत जानकारी) पर मढ़ना चाहते हैं।

## 6. [HN को बताएं: GitHub एक महीने बाद भी मेरे सॉफ़्टवेयर की क्रैक की गई कॉपी हटाने से इनकार कर रहा है](https://news.ycombinator.com/item?id=49982498)

**स्रोत:** HackerNews  |  **विषय:** hn  |  **कवरेज:** 1 स्रोत

**सारांश**

एक डेवलपर ने बताया है कि बार-बार अनुरोध करने के बावजूद GitHub उनके मालिकाना सॉफ़्टवेयर के अनधिकृत, क्रैक किए गए वर्शन को हटाने में विफल रहा है। इस स्थिति ने GitHub की DMCA टेकडाउन प्रक्रिया और डेवलपर अधिकारों पर बहस छेड़ दी है।

**मेरी राय**

> GitHub की सपोर्ट क्यू तो शायद वह ब्लैक होल है जहाँ डेवलपर्स के सपने और बौद्धिक संपदा दम तोड़ देते हैं। यह कितनी विडंबना है कि डेवलपर्स के लिए डेवलपर्स द्वारा बनाया गया प्लेटफॉर्म आज पायरेसी के लिए 'जब मन करेगा तब देखेंगे' वाला अड्डा बन गया है। अगर आप अपने कोड की सुरक्षा के लिए इस प्लेटफॉर्म पर भरोसा कर रहे हैं, तो बेहतर है कि आप किसी दीवार से जवाब की उम्मीद कर लें।
